# api-health-monitor

A lightweight, Dockerized tool for monitoring the uptime and health of your API endpoints.

## Features
- Periodically checks the health of any HTTP/HTTPS endpoint.
- Docker-ready for easy deployment.
- Simple logging system to track status changes.
